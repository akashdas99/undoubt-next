# Read about

Read about explains what Undoubt is. The page is public and does not depend on a question row.

## Sub-features

- `about-open` shows the about heading from the header.

## How to get to it (user POV)

- Choose `About` in the header nav named `Find and ask`.
- Open `http://127.0.0.1:3000/about`.

## Driving it with the Cursor browser

Preconditions:

- The user already has `http://127.0.0.1:3000/` open.

- **Open about.** From the home page, choose `About`. The address is `/about`, the heading `About` is visible, and the sections include `Ask`, `Answer`, and `Find`.
- **Proof.** Save an accessibility snapshot to `evidence/read-about/about.aria.txt` and a screenshot to `evidence/read-about/about.png`. Both show the heading `About`.

## Gotchas

- On a narrow window, `About` is inside the menu opened by `Open menu`.
- The home feed's `Recent Questions` heading is not this page.
